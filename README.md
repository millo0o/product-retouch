# 제품 사진 AI 보정·누끼

제품 실사진을 올리면 AI가 사진을 새로 보정해 줘요(흰 배경, 주름·반사·이물 정리, 스튜디오 조명). 투명 배경 누끼 PNG도 같이 만들고, 라벨 글씨를 원본과 비교해서 틀린 곳을 찾아 줘요.

## 1. 내 컴퓨터 폴더 고르기

| 내 컴퓨터 | 쓸 폴더 |
|---|---|
| 윈도우 | **`윈도우`** 폴더 |
| 맥 | **`맥`** 폴더 |

받는 법: 위의 초록색 **Code → Download ZIP** 을 누르고, 받은 zip을 풀어서 내 컴퓨터 폴더만 쓰면 돼요.
(내 것만 받고 싶으면 오른쪽 **Releases** 에서 `윈도우용` 또는 `맥용` zip을 받아도 돼요.)

## 2. 설치하기 vs 시작하기

| 파일 | 언제 | 하는 일 |
|---|---|---|
| **설치하기** | **처음 딱 한 번** | 필요한 프로그램(파이썬, Codex, 글씨 인식·누끼 도구)을 깔고, 본인 **ChatGPT 계정으로 로그인**해요. 몇 분 걸려요. |
| **시작하기** | **쓸 때마다** | 보정 프로그램이 켜지고, 브라우저에 **대시보드 화면이 자동으로 열려요.** |

- 게임으로 치면, 처음 깔 때 = 설치하기, 게임할 때마다 아이콘 누르기 = 시작하기예요.
- 시작하기를 누르면 같이 뜨는 검은 창(맥은 터미널 창)은 **쓰는 동안 닫지 마세요.** 닫으면 보정이 멈춰요.
- 브라우저 창만 닫았다면 시작하기를 다시 누르세요. 이미 켜져 있으면 화면만 다시 열어 줘요.
- 파일 이름: 윈도우는 `설치하기.bat` · `시작하기.bat`, 맥은 `설치하기.command` · `시작하기.command`
  - 윈도우에서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
  - 맥에서 열리지 않으면 **오른쪽 클릭 → 열기**

## 3. 대시보드에서 쓰는 법

1. **빠른 보정**(약 4분) 또는 **꼼꼼 보정**(약 10분)을 고르고, 사진을 끌어다 놓아요. 여러 장도 돼요(동시에 2장씩).
   - 빠른 보정: AI 보정 1번 + 글씨 검사. 틀린 글씨는 표시만 해요.
   - 꼼꼼 보정: 라벨 글씨를 다시 그리고 틀린 낱말까지 고쳐요. 빠른 보정이 끝난 사진은 **"꼼꼼 보정하기"** 버튼으로 이어서 할 수 있어요.
2. 진행 상황이 1초마다 화면에 보여요.
3. 끝나면 원본·보정본·누끼를 비교해 보고, 따로 받거나 ZIP으로 한꺼번에 받아요.
4. **판매용으로 쓰기 전에** "글씨 확인"의 원본·보정본 줄 비교표를 꼭 한 번 훑어보세요. 자동 검사가 100%는 아니에요.

결과는 바탕화면의 **`제품보정`** 폴더에 쌓여요.

## 준비물

- **ChatGPT 계정**(이미지 생성이 되는 요금제). 본인 계정 사용량을 써요. API 요금은 따로 없어요.
- 인터넷 (처음 설치할 때 약 300MB를 내려받아요)

## 알아 둘 것

- 바코드는 숫자만 맞춰요. 막대 무늬는 AI가 그린 거라 실제로 스캔되지 않을 수 있어요.
- 오류가 나면 `제품보정/결과물/<사진번호>/실행기록.txt` 를 보내 주세요.
- 더 자세한 내용은 각 폴더의 `사용법.txt` 에 있어요.
