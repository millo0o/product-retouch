# 제품 사진 AI 보정·누끼

제품 실사진을 올리면 AI가 사진을 새로 보정해 줍니다(흰 배경, 주름·반사·이물 정리, 스튜디오 조명). 투명 배경 누끼 PNG도 같이 만들어요.
라벨 글씨는 원본과 한 글자씩 비교해서, 틀린 곳을 찾아 고치거나 표시해 줍니다.

- **빠른 보정** (약 4분): AI 보정 1번 + 글씨 검사. 틀린 글씨는 화면에 표시만 해요.
- **꼼꼼 보정** (약 10분): 라벨 글씨를 다시 그리고 틀린 낱말까지 고쳐요. 빠른 보정이 끝난 사진은 "꼼꼼 보정하기" 버튼으로 이어서 할 수 있어요.

## 내려받기 (쓰는 분)

**[Releases](https://github.com/millo0o/product-retouch/releases/latest)** 에서 자기 컴퓨터 것 **하나만** 받으세요.

- 윈도우: `제품보정-윈도우-<버전>.zip`
- 맥: `제품보정-맥-<버전>.zip`

풀면 맨 위에 `설치하기` · `시작하기` · `사용법.txt` 가 있어요. `사용법.txt` 대로 하면 돼요.
(아래 내용은 이 저장소를 직접 고치는 사람용이에요. 묶음은 `python3 배포/묶음만들기.py <버전>` 으로 만들어요.)

## 준비물

- **ChatGPT 계정**: 이미지 생성이 되는 요금제여야 해요. 본인 계정의 사용량을 씁니다(API 요금은 따로 없음).
- 윈도우 10/11 또는 맥
- 인터넷 (처음 설치할 때 프로그램과 모델 약 300MB를 내려받아요)

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| **`윈도우/`** | 윈도우에서 누를 파일 (설치하기.bat, 시작하기.bat) |
| **`맥/`** | 맥에서 누를 파일 (설치하기.command, 시작하기.command) |
| `scripts/`, `prompts/`, `templates/` | 프로그램 본체 (윈도우·맥 같이 씀, 건드리지 않아도 돼요) |
| `scripts/mac/` | 맥 전용 글씨 인식·누끼 도구 소스 |

폴더는 통째로 두고 쓰세요. `윈도우`·`맥` 폴더만 따로 빼면 실행되지 않아요.

## 설치 (처음 한 번)

### 윈도우
1. 이 폴더를 원하는 곳에 둡니다 (예: `내 문서\제품보정프로그램`).
2. **`윈도우` 폴더의 `설치하기.bat`** 을 두 번 누릅니다.
   - 파이썬이나 Node.js가 없으면 자동으로 설치해요. 끝나면 "다시 실행해 주세요"라고 나오니, 한 번 더 누르세요.
   - 마지막에 브라우저가 열리면 **본인 ChatGPT 계정으로 로그인**하세요.
3. "설치 끝!"이 나오면 됩니다.

> "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

### 맥
1. 이 폴더를 원하는 곳에 둡니다.
2. **`맥` 폴더의 `설치하기.command`** 를 두 번 누릅니다. (막히면 오른쪽 클릭 → 열기)
   - 맥 개발 도구가 없으면 설치 창이 떠요. 설치가 끝나면 한 번 더 실행하세요.
   - 브라우저가 열리면 본인 ChatGPT 계정으로 로그인하세요.

## 쓰는 법

1. **`윈도우/시작하기.bat`** (맥은 `맥/시작하기.command`) 을 두 번 누르면 브라우저에 대시보드가 열려요.
   - 검은 창은 쓰는 동안 **닫지 마세요**. 닫으면 보정이 멈춥니다.
2. 빠른 보정 / 꼼꼼 보정을 고르고 사진을 끌어다 놓으세요. 여러 장도 돼요 (동시에 2장씩 처리).
3. 끝나면 원본·보정본·누끼를 비교해 보고, 따로 받거나 ZIP으로 한꺼번에 받으세요.
4. **판매용으로 쓰기 전에** "글씨 확인"의 원본·보정본 줄 비교표를 꼭 한 번 훑어보세요. 자동 검사가 100%는 아니에요.

결과는 바탕화면의 **`제품보정`** 폴더에 쌓여요 (`원본`, `결과물`, 목록에서 뺀 건 `_휴지통`).

## 설정 바꾸기 (필요할 때만)

`config.example.json` 을 복사해 이름을 `config.json` 으로 바꾸고 고치면 돼요.

| 칸 | 뜻 | 비우면 |
|---|---|---|
| `codex_home` | 다른 ChatGPT 계정 폴더를 쓸 때 | 기본 계정 (`~/.codex`) |
| `work_dir` | 결과를 쌓을 폴더 | 바탕화면\제품보정 |
| `port` | 대시보드 주소 번호 | 8767 |
| `workers` | 동시에 보정할 사진 수 | 2 |

## 알아 둘 것

- 바코드는 숫자만 맞춰요. 막대 무늬는 AI가 그린 거라 실제로 스캔되지 않을 수 있어요.
- 글씨 읽기: 맥은 맥 내장 기능, 윈도우는 RapidOCR(한국어 모델)을 써요. 작은 글씨가 아주 빽빽하면 윈도우 쪽이 조금 덜 읽을 수 있어요. 덜 읽힌 줄은 "눈으로 확인"으로 표시돼요.
- 오류가 나면 `제품보정\결과물\<사진번호>\실행기록.txt` 를 보내 주세요.
